# Plan: Implement UpdateProgress Method

## Context
`ProgressRepository.UpdateProgress(string UserId, long BookId)` is an empty stub that won't compile. The `Progress` model exists with fields `Id` (long), `UserId` (string), `BookId` (long). The DbSet is already registered as `Progresses`.

## Implementation
**File**: `Repositories\ProgressRepository.cs`

Make the method `async`, query `db.Progresses` by `UserId`, update `BookId`, and call `SaveChangesAsync`:

```csharp
public async Task UpdateProgress(string UserId, long BookId)
{
    var progress = await db.Progresses.FirstOrDefaultAsync(p => p.UserId == UserId);
    if (progress != null)
    {
        progress.BookId = BookId;
        await db.SaveChangesAsync();
    }
}
```

This follows the existing repository patterns: async/await, LINQ query, `SaveChangesAsync`.
