# Plan: 添加 CET6 单词分页查询接口

## 任务目标
为 CET6Book 添加一个分页查询接口，返回六级词汇书中的单词数据。

## 需求确认
- **数据量**: 5000+ 条
- **获取方式**: 分页查询（参考 `UserRepository.GetUserPage` 模式）
- **认证要求**: 需要登录 `[Authorize(Roles = RoleType.User)]`
- **默认每页**: 20 条

## 实施步骤

### 1. 添加分页 DTO
**文件**: `Dtos/Cet6BookDto.cs` (新建)

创建 `Cet6BookDto` 返回 DTO，包含：
- `Id`, `Word`, `Translate`
- 3组干扰词及翻译

### 2. 补充 CET6BookRepository 分页方法
**文件**: `Repositories/CET6BookRepository.cs`

添加 `GetPage(int pageNumber, int pageSize)` 方法：
- 按 Id 排序
- Skip/Take 分页
- 返回 `List<Cet6BookDto>`

### 3. 创建 CET6BookController
**文件**: `Controllers/CET6BookController.cs` (新建)

```
[ApiController]
[Route("[controller]")]
```

添加分页查询端点：
```
GET /cet6book/page?number=1&size=20
[Authorize(Roles = RoleType.User)]
```

### 4. 注册 CET6BookRepository 到 DI
**文件**: `Program.cs`

添加 `builder.Services.AddScoped<CET6BookRepository>();`

### 5. 更新 AGENTS.md
**文件**: `AGENTS.md`

添加 CET6BookController 的 API 端点文档。

## 关键文件
- `Models/CET6Book.cs` - 实体（已有）
- `Datas/EWordDbContext.cs` - DbSet 已有 `Cet6Books`
- `Dtos/Cet6BookDto.cs` - 新建
- `Repositories/CET6BookRepository.cs` - 补充分页方法
- `Controllers/CET6BookController.cs` - 新建
- `Program.cs` - 注册服务

## 验证方式
1. `dotnet build` 编译通过
2. 启动后 Swagger 可见 `/cet6book/page` 端点
3. 用 JWT Token 调用 `GET /cet6book/page?number=1&size=20` 返回 20 条数据
4. 翻页 `number=2` 返回下一批数据
